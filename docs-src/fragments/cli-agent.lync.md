## 🤖 LLM 驱动自治模式 (Agent 命令)

大模型辅助编程时代，为了避免 Lync 内部调取网络大模型 API 造成的 Token 浪费以及上下文断裂，作为统管全局的 AI 助手，你应该原生使用自治模式驱动编译：
```bash
lync agent
```

在该模式下，Lync 将阻断所有的跨语种自动翻译等内部大模型请求，仅执行光速的 AST 静态组装计算。

编译完成后，Lync 会在项目的隐藏目录下输出一份机器可读的指令清单：
**`.lync/agent-instructions.md`**

### AI 助手操作规程

每当你替人类执行了 `lync agent` 命令，你**必须立即读取 `.lync/agent-instructions.md`** 中的指令。

这份文件会将以下高级语义任务交棒给你的聪明大脑：
1.  **冲突检查 (Verify)**：读取 Lync 提供给你的体积最小的最终 Prompt，审查是否存在自相矛盾或系统破坏风险。（等效于独立命令 `lync lint`，但由你直接在上下文中执行，零额外 API 开销。）
2.  **语义裁剪 / Tree-shaking**：结合用户当前的微小意图，判断刚刚组装出来的大型 Prompt 树中，是否有哪些分支是不必要的，并代为实施"摇树优化"。
3.  **跨语种翻译补全**：如果指令中包含了预期的多个 `Target Languages`，你有责任原封不动地保留所有 Markdown AST 结构，将该源语言核心文件完美翻译到其他要求语种的文件中。
4.  **历史差异 (Diffing)**：如果 Lync 悄悄在 `.lync/cache/history-*` 帮你备份了上一版文件，请去读取它，并向人类用户总结本次编译究竟在**底层结构上影响了什么**。（等效于独立命令 `lync diff`。）

你是统筹全局的智能主体，而 Lync 是你最可靠的确权肌肉。
